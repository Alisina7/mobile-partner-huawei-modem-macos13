Mobile Partner for macOS 13

This installer turns the 2013 Huawei E1550 “Mobile Partner” software into a working 64-bit modem app for macOS 13.

  • Installs Mobile Partner, a native SwiftUI replacement.
  • Installs the 64-bit HuaweiDataCardDriver kernel extension and the Huawei PPP modem script.
  • Installs a small privileged helper that creates and controls the macOS PPP service.

A reboot is required after installation.

macOS 13 stages third-party kernel extensions for the next boot. The modem serial ports will not appear until you restart.

The original 32-bit Mobile Partner interface cannot run on macOS 13 at all; this package preserves the modem functionality with a new native interface.
